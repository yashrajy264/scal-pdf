## 🆘 **Troubleshooting**

### **"Permission denied" Error:**
```bash
chmod +x ScalPDF
```

### **"Cannot execute binary file":**
- Make sure you're on a compatible system (Linux/macOS)
- Check architecture compatibility (x86_64/ARM64)

### **macOS "Cannot open" Error:**
```bash
# Allow unsigned applications (if needed)
xattr -d com.apple.quarantine ScalPDF.app
```

### **GUI doesn't appear:**
- Make sure you're in a desktop environment
- Check that DISPLAY is set (for X11)
